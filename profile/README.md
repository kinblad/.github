# Kinblad

Software house. We build custom systems for companies with a real process to run.

Multilingual e-commerce and stores. B2B portals with per-customer price lists, catalogues, orders and order status. Integrations between ERP, CRM, logistics and invoicing, where data passes through once only. Agents that read company systems with explicit permissions and an operations log. Migrations, maintenance, infrastructure. Data pipelines and operational dashboards.

The method: first you map the process that exists, then you decide what to automate. No system is written on a flow that has not been observed.
